DOCUMENT R02 — System conditions data, 9 August 2019
Owner/originator: Elexon Limited (BMRS / Insights API data, much of it supplied by the system
operator); National Energy System Operator (NESO) open data portal; National Grid ESO (technical
report tables)
Record type: real public dataset extracts (CSV files) with two published report tables and this
metadata note
STATUS: REAL DATA EXTRACTS WITH TRANSCRIBED REPORT TABLES — dataset values are unchanged from the
publishers' files (only rows and columns were selected); report tables, captions and quotations
are reproduced as printed. Nothing in this record is synthesised.
Clock reference: stated for each file and table below. Elexon timestamps are UTC (ISO-8601 with
Z). Elexon and NESO settlement periods are numbered on the UK local clock: period 1 starts at
00:00 local time and each period lasts 30 minutes. UK local time on 9 August 2019 was BST
(UTC+01:00).
Value-status legend: [measured] metered or observed value as published; [reported] value stated by
its publisher or by a report; [estimated] value its source describes as an estimate; [modelled]
value produced by a model; [digitised] and [illustrative] are not used.

PART A — HOW TO USE THIS RECORD
A1  The CSV files described in Part B are delivered with this note; after retrieval they are in
    $EVIDENCE_DIR/R02/. Dataset values are copied without rounding, unit conversion, interpolation
    or gap filling. CSV conventions for files built from the publishers' JSON: comma-separated,
    UTF-8, LF line endings, one header row; numbers as published; true/false for JSON booleans; an
    empty cell for JSON null. The two NESO files keep the publisher's own lines byte for byte
    (CRLF line endings).
A2  Unit-level metered volumes (B8) and Maximum Export Limit records (B9) are also available
    through query_asset_log for assets HORNSEA-ONE and LITTLE-BARFORD; each row there has an event
    ID and cites R02.
A3  Cite this note with L<n> or L<a>-L<b> (line numbers shown on retrieval).

PART B — PUBLIC DATASET EXTRACTS (one block per file)
B1  File R02_elexon_fuelinst_5min_20190809.csv [measured] — generation outturn by fuel type,
    5-minute values.
    Source: Elexon BMRS dataset FUELINST, Elexon Insights API endpoint /datasets/FUELINST queried
    with publishDateTimeFrom=2019-08-09T14:00:00Z and publishDateTimeTo=2019-08-09T19:00:00Z;
    retrieved 2026-10-20. Publisher: Elexon Limited. Licence: Elexon BMRS open data licence.
    Contains BMRS data (c) Elexon Limited copyright and database right 2026.
    Rows: 61 (every row returned), one per startTime from 2019-08-09T13:55:00Z to
    2019-08-09T18:55:00Z. The API returns one record per fuel type; the file has one column per
    fuel type instead. No totals are added.
    Columns: startTime, publishTime (UTC); settlementDate, settlementPeriod (UK local clock);
    BIOMASS, CCGT, COAL, INTEW, INTFR, INTIRL, INTNED, INTNEM, NPSHYD, NUCLEAR, OCGT, OIL, OTHER,
    PS, WIND (MW). INT* codes are interconnectors; PS is pumped storage; NPSHYD is
    non-pumped-storage hydro (publisher's fuel-type codes).
    Publisher's description: "average MW values over 5 minutes for each category". The data do not
    say whether startTime is the start of the averaging interval, so treat the time of each
    FUELINST value as uncertain by up to 5 minutes. Embedded (distribution-connected) generation
    is not included.
B2  File R02_elexon_fuelhh_halfhour_20190809.csv [measured] — generation outturn by fuel type,
    half-hourly.
    Source: Elexon BMRS dataset FUELHH, endpoint /datasets/FUELHH queried for settlementDate
    2019-08-09; retrieved 2026-10-20. Licence as B1.
    Rows: 48, settlement periods 1-48 of 2019-08-09, in period order. Columns as B1; startTime is
    the UTC start of the settlement period, except that the publisher dates the period-48 row
    2019-08-08T22:30:00Z (kept as published). Publisher's description: "average MW values over 30
    minutes for each category".
    Caveat: on this date the FUELHH value of some settlement periods equals the mean of only the
    first five of the six FUELINST values in that period, not of all six. Do not use FUELHH to
    time changes within a half hour or to check FUELINST.
B3  File R02_elexon_indo_itsdo_20190809.csv [measured] — initial demand outturn, half-hourly.
    Source: Elexon endpoint /demand/outturn queried for settlementDate 2019-08-09; retrieved
    2026-10-20. Licence as B1.
    Rows: 48, settlement periods 1-48. Columns: publishTime, startTime, settlementDate,
    settlementPeriod, initialDemandOutturn, initialTransmissionSystemDemandOutturn. startTime is
    the UTC start of the period and publishTime its end (UTC); values MW.
    Publisher's description: INDO "measures the half-hour average MW demand metered by the
    Transmission Company based on its operational metering"; INDO "takes into account transmission
    losses but does not include station transformer load, pumped storage demand or interconnector
    demand", while ITSDO includes them.
B4  File R02_neso_historic_demand_20190808-10.csv [measured] — NESO historic demand data,
    half-hourly, 8-10 August 2019; its embedded generation columns are [modelled].
    Source: NESO open data portal, Historic Demand Data 2019 (demanddata_2019.csv); retrieved
    2026-10-20. Licence: NESO Open Data Licence v1.0. Supported by National Energy SO Open Data.
    Rows: 144 (48 per day for 08-AUG-2019, 09-AUG-2019 and 10-AUG-2019), copied from the
    publisher's file byte for byte with its header line. Columns: SETTLEMENT_DATE,
    SETTLEMENT_PERIOD, ND, TSD, ENGLAND_WALES_DEMAND, EMBEDDED_WIND_GENERATION,
    EMBEDDED_WIND_CAPACITY, EMBEDDED_SOLAR_GENERATION, EMBEDDED_SOLAR_CAPACITY, NON_BM_STOR,
    PUMP_STORAGE_PUMPING, IFA_FLOW, IFA2_FLOW, BRITNED_FLOW, MOYLE_FLOW, EAST_WEST_FLOW,
    NEMO_FLOW, NSL_FLOW, ELECLINK_FLOW, VIKING_FLOW, GREENLINK_FLOW (MW).
    Publisher's documentation: "All values are an average over the half hour." and "All times are
    UK time and for the half hour beginning." SETTLEMENT_DATE is written DD-MON-YYYY.
